# Twitter Kickstart Pack

Starter pack for posting consistently about **Polymarket radar** and **edge hunting**.

Files:
- `templates.md` — reusable tweet templates and frameworks
- `7-day-plan.md` — a simple one-week execution plan
- `draft-tweets.md` — 3 ready-to-post drafts (edit before posting)

Guiding principles:
- Be clear: what happened → why it matters → what to watch next
- Include numbers (p(YES), Δ1h/Δ24h, volume) when possible
- Avoid overclaiming; label hypotheses as hypotheses
- Always link to the market/event when referencing it
